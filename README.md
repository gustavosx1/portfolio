# Portfólio — Gustavo Rocha

Site oficial do portfólio de Gustavo Rocha, desenvolvido com Next.js, TypeScript e Tailwind CSS. Reúne projetos selecionados, tecnologias e formas de contato em uma interface responsiva de tema escuro.

## Executar localmente

Requer Node.js 20.9 ou superior. Instale as dependências e inicie o servidor de desenvolvimento:

```sh
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Comandos disponíveis

- `npm run dev` — servidor de desenvolvimento.
- `npm run lint` — verificação estática com ESLint.
- `npm run build` — compilação de produção.
- `npm start` — inicia a versão compilada.

## Estrutura

- `src/app/page.tsx` — conteúdo e projetos do portfólio.
- `src/app/globals.css` — tema, layout e estilos responsivos.
- `src/app/layout.tsx` — metadados e layout global.

O projeto usa Next.js App Router e Tailwind CSS. Consulte a [documentação do Next.js](https://nextjs.org/docs) para informações sobre desenvolvimento e publicação.
